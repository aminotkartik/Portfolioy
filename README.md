# Yash Thakur — Portfolio

A responsive, single-page portfolio for Yash Thakur's first-year FESA representative application. Built with HTML, CSS, and vanilla JavaScript; no build step required.

## Run locally

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Open port 3000. The page includes mobile navigation, section links, academic achievements, leadership experience, creative milestones, and a FESA vision section. **Save my profile** opens the browser print dialog, where the profile can be saved as a PDF with print-specific styling.

Content lives in `index.html`, styling in `style.css`, and menu/print behavior in `script.js`. Google Fonts are optional; local system font fallbacks are provided. No personal photo, contact details, or social handle have been invented.
